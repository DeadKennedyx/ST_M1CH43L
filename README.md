# ST_M1CH43L

A minimal static blog built for GitHub Pages.

## Publish

1. Create a GitHub repository named `ST_M1CH43L`.
2. Push these files to the repository's `main` branch.
3. In **Settings → Pages**, set **Source** to **GitHub Actions**.

The published project URL will be:

```text
https://YOUR-GITHUB-USERNAME.github.io/ST_M1CH43L/
```

## Edit posts

The home-page entry list is in `index.html`. Individual articles live in `posts/`.
The generated Saint Michael artwork lives at `assets/st-michael.png`.
